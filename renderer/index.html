            What Auto Mode does
            
            
          
            
          
            
            
            
              
            Tailor boosts to my PC
            
              
            FrameForge reads your hardware and switches on only the boosts that help this exact system. Changing a boost below by hand overrides it.
            
            
            
            
          
            
          
            
        
            

        
            
          
            Chris Titus Tech’s Windows Utility
            
          
            
            
            
              
            Preset Auto Mode runs
            
              
            Minimal: telemetry and background services only. Standard: Chris Titus’s recommended set — also turns off activity history and location services, and runs Disk Cleanup. Advanced: also removes OneDrive, Widgets and Windows AI features and brings back the old right-click menu — only if you’re sure.
            
            
            
            
          
            
          
            
            
            
              
            Open the Chris Titus tool after Auto Mode
            
              
            When Auto Mode has run the preset, open Chris Titus’s own window so you can see and check the tweaks.
            
            
            
            
          
            
          
            
            
            
              
            Open the tool
            
              
            Opens winutil’s own window to install apps or pick extra tweaks by hand, or to undo its tweaks.
            
            
            
            
          
            
        
            

        
            
          
            Overclocking
            
          
            
            
            
              
            Overclock automatically
            
              
            Uses the safe limits built into your graphics card. On NVIDIA, FrameForge raises the power limit to the card’s maximum by itself; for clock speeds it opens your vendor’s own auto-tuner, which stress-tests your chip. Higher temperatures and power draw. Undone when you turn Auto Mode off.
            
            
            
            
          
            
        
            

        
            
          
            Downloads
            
          
            
            
            
              
            Download performance tools
            
              
            Lets Auto Mode download free tools it needs: PresentMon by Intel (FPS counter), LibreHardwareMonitor (temperatures), and your driver app if it’s missing.
            
            
            
            
          
            
          
            
            
            
              
            Open my driver app after boosting
            
              
            Opens AMD Software, the NVIDIA app or Intel Graphics Software so you can finish the driver tune-up.

            Windows
            
          
            
            
            
              
            Windows animations
            
              
            On: enables Windows animations and shows app contents while you drag windows. Also restores shadows, smooth fonts, selection effects and thumbnail previews. Off: disables Windows animations, menu and tooltip fades, taskbar animations, Peek and live window contents while dragging. Animation and dragging changes apply right away; some Explorer effects may need you to sign out. FrameForge keeps your choice if another tool changes it. Apps that draw their own effects may have separate settings. Transparency is controlled separately in Tweaks.

            Virus scan
            
          
            
            
            Scheduled quick scan
            Runs by itself while you’re away from the PC (10+ minutes idle, no game running, laptops only on the charger). It steps aside the moment you’re back. If it finds something you get a notification, and nothing is removed until you choose.
            
            
          
            
          
            
            
            Scheduled full scan
            Checks every file on every internal drive the same way — it takes a while, so it only runs when you’re away, at low priority. A full scan also counts as the quick scan.
            
            
          
            
          
            
            
            Check detections against the known-software database
            Part of the false-positive check: looks up a flagged file’s SHA-256 fingerprint in CIRCL’s hashlookup (NIST’s National Software Reference Library and official Windows builds). Only the fingerprint of flagged files is sent — never the file.
            
            
          
            
        
            

        
            
          
            Fix mode
            
          
            
            
            Fix problems by itself
            FrameForge checks the PC every 2 minutes and fixes what it safely can without a click: tweaks Windows switched off, a display stuck at 60 Hz, a hot graphics card, missing tools. Mid-game it only does things you won’t notice; cleanups and the Chris Titus tool wait until you’ve been away for 10 minutes. You get a notification for everything it fixed.
            
            
          
            
          
            
            
            Restart the PC by itself when a fix needs it
            Shows a 60-second countdown with Cancel and Restart now, then restarts and opens FrameForge again to finish. In the background it only restarts after you’ve been away for 20 minutes with no game running, and never twice within 3 hours. Apps with unsaved work can still stop the restart.
