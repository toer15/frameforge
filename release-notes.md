**Fix Mode recovery**

- With **Fix problems by itself** enabled, FrameForge retries a supported Windows tweak once if it fails in the Tweaks tab or during Auto Mode.
- FrameForge reads the saved Windows values before reporting a recovery under **Fixed just now**. A failed retry stays visible in Fix Mode with the error.
- Corrected registry paths for Windows Search indexing, Delivery Optimization, and diagnostics in the Extreme Performance preset.
