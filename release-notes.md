**"Fix everything automatically" now really fixes everything it can — by itself**

The fixer is built into FrameForge: it works offline, with nothing to set up and no account or key. For every problem it knows several fixes, tries them in order, and checks after each one that the problem is really gone. You watch it work in a live report.

**It fixes by itself**
- Display stuck below its refresh rate (e.g. 60 Hz on a 165 Hz monitor) → switches to the highest rate, tested first so the screen never goes black
- Tweaks Windows switched back off after an update → turns them back on
- Failed steps → tries again, then other ways (e.g. a fresh copy of the Chris Titus tool, turning on System Protection for restore points)
- Missing FPS / temperature tools → downloads them
- Missing NVIDIA / Intel driver app → installs it from Microsoft's verified store
- Drive C: almost full → clears temp files and old Windows update leftovers
- Graphics card too hot after overclocking → puts the power limit back
- Not running as administrator → restarts as admin and carries on fixing by itself

**For what only you can do**, it gives step-by-step instructions for your PC — e.g. the exact BIOS menu to turn on XMP/EXPO for ASUS, MSI, Gigabyte or ASRock boards, cooling steps for hot parts, cable advice for the display, and a Restart button when one is needed.

**New tweak:** Use your monitor's highest refresh rate (Tweaks tab, and part of every preset).
